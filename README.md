# BookMyVenue

A cloud-native venue booking platform with an agentic AI-driven security layer, built on Azure.
Built by Zahwa & Manas as a dual submission for DBMS and Cloud Computing coursework.

Originated from an MIT-licensed open-source scaffold by the WeCode community
(React + Vite + Tailwind starter); all schema, backend, and application logic below is original.

## Stack
- Frontend: React + Vite + Tailwind → Azure Static Web Apps
- Backend: Node.js + Express → Azure App Service
- Database: PostgreSQL → Azure Database for PostgreSQL Flexible Server
- AI Security Agent: Azure Functions + LLM API
